# Tiny Tasks

Простой список задач в терминале на Python. Добавляйте задачи, отмечайте выполненные и возвращайтесь к списку после перезапуска. Данные хранятся локально в JSON.

Проект подходит для первого репозитория на GitHub: один файл приложения, стандартная библиотека Python и понятные тесты.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки устанавливать не нужно.

Скачайте проект, откройте терминал в папке с `tasks.py` и выполните:

```bash
python tasks.py add "Подготовиться к экзамену"
python tasks.py add "Загрузить первый проект на GitHub"
python tasks.py done 1
python tasks.py list
```

Результат:

```text
[x] #1  Подготовиться к экзамену
[ ] #2  Загрузить первый проект на GitHub
```

Если команда `python` не найдена, в Windows попробуйте `py`, а в macOS или Linux — `python3`.

## Команды

| Команда | Действие |
| --- | --- |
| `python tasks.py add "Купить продукты"` | Добавить задачу |
| `python tasks.py list` | Показать все задачи |
| `python tasks.py list --status active` | Показать незавершённые |
| `python tasks.py list --status done` | Показать выполненные |
| `python tasks.py done 1` | Отметить задачу №1 выполненной |
| `python tasks.py undo 1` | Вернуть задачу №1 в работу |
| `python tasks.py delete 1` | Удалить задачу №1 без возможности отмены |
| `python tasks.py --help` | Открыть справку |

Номера задач не меняются после удаления других записей.

## Хранение данных

После добавления первой задачи приложение создаст `data/tasks.json` рядом со скриптом. Файл исключён из Git через `.gitignore`, чтобы личные задачи не попадали в репозиторий.

Для отдельного списка укажите путь перед командой:

```bash
python tasks.py --file data/study.json add "Прочитать главу"
python tasks.py --file data/study.json list
```

Приложение рассчитано на одного пользователя и последовательный запуск команд. Не изменяйте один файл одновременно из нескольких процессов. Если JSON повреждён, программа сообщает об ошибке и сохраняет исходный файл.

## Проверка

```bash
python -m unittest -v
```

Тесты проверяют сохранение задач, кириллицу, изменение статуса, удаление, фильтрацию и обработку повреждённых данных. Они используют временные папки и не затрагивают ваш список.

## Загрузка на GitHub

1. Создайте пустой репозиторий с названием `tiny-tasks`.
2. Загрузите содержимое этой папки, включая `.gitignore` и каталог `.github`, в корень репозитория. ZIP-архив предварительно распакуйте.
3. В описание репозитория можно вставить: `A simple Python CLI task manager with local JSON storage and no dependencies.`

В `.github/workflows/tests.yml` находится проверка тестов через GitHub Actions для Windows и Linux.
